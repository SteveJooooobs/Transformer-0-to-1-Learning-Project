# Transformer 概述

> 本文从零开始介绍 Transformer 架构的背景、动机和核心思想，帮助你理解「为什么需要 Transformer」。

---

## 一、从 RNN 到 Transformer：为什么需要变革？

在 Transformer 出现之前，处理序列数据（如文本、语音）的主流模型是 **循环神经网络（RNN）** 及其变体 **LSTM** 和 **GRU**。

### RNN 的工作方式

RNN 像「阅读」一样逐字处理序列：

```
输入:  "我 爱 学 习"
       ↓   ↓   ↓   ↓
处理:  h₁→ h₂→ h₃→ h₄
```

每一步的隐藏状态 `h_t` 依赖于上一步的 `h_{t-1}`，形成一条链式计算路径。

### RNN 的三大局限

| 问题 | 说明 |
|------|------|
| **顺序计算** | 必须一步一步地处理，无法并行化。一个长序列需要依次计算 N 步，训练速度很慢。 |
| **长距离依赖** | 当序列很长时，第 1 个词的信息需要经过很多步才能传到最后一个词，信息在传递过程中逐渐「衰减」。 |
| **梯度消失/爆炸** | 反向传播时，梯度需要沿着链式路径回传，经过多次乘法后容易变得极小（消失）或极大（爆炸）。 |

> 💡 LSTM 和 GRU 通过引入「门控机制」部分缓解了梯度问题，但**顺序计算**的根本限制无法突破。

## 二、Transformer 的核心思想

2017 年，Google 团队在论文《Attention Is All You Need》中提出了 Transformer，核心思想可以用一句话概括：

> **用「注意力机制」替代「循环结构」，让序列中的每个位置都能直接关注任意其他位置。**

### 与 RNN 的对比

```
RNN:   词1 → 词2 → 词3 → 词4    （链式依赖，必须按顺序）

Transformer:
       词1 ←→ 词2
       词1 ←→ 词3    （每个词都能直接看到其他所有词）
       词1 ←→ 词4
       词2 ←→ 词3
       ...
```

这带来了两个关键优势：
1. **可以并行计算**：所有位置可以同时处理，训练速度大幅提升
2. **直接长距离依赖**：任意两个位置之间只需要一步就能「交流」信息

## 三、Transformer 的整体架构

Transformer 采用经典的 **编码器-解码器（Encoder-Decoder）** 架构：

```
源序列 (如：一段英文)     目标序列 (如：对应的中文翻译)
        ↓                           ↓
   ┌─────────┐                ┌──────────┐
   │ 词嵌入层 │                │  词嵌入层 │
   │+ 位置编码│                │+ 位置编码 │
   └────┬────┘                └────┬─────┘
        ↓                          ↓
   ┌─────────┐                ┌──────────┐
   │ 编码器   │───Memory──→   │  解码器   │
   │(Encoder) │    传递       │(Decoder)  │
   │ N 层堆叠 │               │ N 层堆叠  │
   └─────────┘                └────┬─────┘
                                   ↓
                              ┌──────────┐
                              │ 线性输出层│
                              │ + Softmax │
                              └──────────┘
                                   ↓
                              输出预测概率
```

### 编码器（Encoder）
- 接收源序列，生成包含全局上下文信息的特征表示（Memory）
- 每一层包含：**自注意力层** + **前馈网络** + **残差连接** + **层归一化**

### 解码器（Decoder）
- 接收目标序列和编码器的 Memory，逐步生成输出
- 每一层包含：**掩码自注意力** + **交叉注意力** + **前馈网络** + **残差连接** + **层归一化**
- 掩码确保解码器在预测第 t 个词时只能看到前 t-1 个词

## 四、Transformer 的深远影响

Transformer 架构成为了现代 AI 的基石，催生了众多里程碑式的模型：

| 模型 | 年份 | 基于 | 特点 |
|------|------|------|------|
| **BERT** | 2018 | 编码器 | 双向理解，适合文本分类、问答 |
| **GPT** 系列 | 2018+ | 解码器 | 自回归生成，适合文本生成、对话 |
| **T5** | 2019 | 编码器-解码器 | 统一文本到文本框架 |
| **Vision Transformer (ViT)** | 2020 | 编码器 | 将 Transformer 应用于图像 |
| **ChatGPT** | 2022 | 解码器 | 大规模语言模型的突破 |

> 💡 可以说，理解 Transformer 就是理解现代 AI 的基础。

## 五、本项目的目标

本项目（From-Scratch Transformer Lab）将带你：

1. **从零实现** 完整的 Encoder-Decoder Transformer
2. **逐模块理解** 每个组件的原理和代码
3. **动手训练** 一个字符级的文本生成模型
4. **实验验证** 不同超参数对模型的影响

我们使用 **Tiny Shakespeare**（莎士比亚戏剧文本）数据集，任务是：
给定一段文本，预测紧接着的下一段文本。

模型规模刻意保持较小（d_model=128, 2 层），确保在 CPU 上也能完成训练。

# 训练过程详解

> 本文详细解释 Transformer 模型的训练流程，包括损失函数、Teacher Forcing、优化器选择、训练观察方法和常见问题。

## 一、交叉熵损失函数

### 什么是交叉熵？

Transformer 的输出是一个**概率分布**（对词表中每个 token 的预测概率）。我们需要一个指标来衡量预测分布与真实分布的差距——这就是**交叉熵损失**（Cross-Entropy Loss）。

$$\mathcal{L} = -\sum_{i} y_i \log(\hat{y}_i)$$

其中：
- $y_i$ 是真实标签（one-hot 编码，正确 token 处为 1，其余为 0）
- $\hat{y}_i$ 是模型预测的概率

简化后（因为 $y_i$ 只有一个位置为 1）：

$$\mathcal{L} = -\log(\hat{y}_{\text{正确token}})$$

### 直觉理解

| 预测正确 token 的概率 | Loss |
|-------|------|
| 90% | -log(0.9) = 0.105 ← 低，很好 |
| 50% | -log(0.5) = 0.693 ← 中等 |
| 10% | -log(0.1) = 2.303 ← 高，很差 |
| 1% | -log(0.01) = 4.605 ← 非常高 |

> 💡 Loss 越低，说明模型对正确答案越「自信」。

### 代码实现

```python
criterion = nn.CrossEntropyLoss(ignore_index=PAD_ID)
# ignore_index=PAD_ID: 忽略 padding 位置的损失
# padding 不是真实数据，不应影响训练

loss = criterion(
    logits.reshape(-1, vocab_size),     # [B*L, vocab_size]
    target.reshape(-1)                   # [B*L]
)
```

## 二、Teacher Forcing

### 什么是 Teacher Forcing？

在训练 Seq2Seq 模型时，解码器需要一个输入来生成下一个 token。有两种选择：

| 方式 | 解码器输入 | 优缺点 |
|------|-----------|--------|
| **Free Running** | 模型自己上一步的预测 | 错误会累积，训练不稳定 |
| **Teacher Forcing** | 真实的目标序列 | 训练稳定，收敛快 |

### Teacher Forcing 的工作方式

```
目标序列: [H, e, l, l, o]

解码器输入:  [<bos>, H, e, l, l]    ← 右移一位的真实序列
预测目标:    [H,     e, l, l, o]    ← 对应的下一个 token
```

本项目中的实现：

```python
# tgt: [B, seq_len]  ← 完整目标序列
tgt_input  = tgt[:, :-1]   # 解码器输入：去掉最后一个
tgt_output = tgt[:, 1:]    # 预测标签：去掉第一个
```

## 三、优化器的选择

### 为什么选择 Adam？

| 优化器 | 特点 |
|--------|------|
| SGD | 简单，但需要仔细调节学习率 |
| **Adam** | 自适应学习率，不同参数使用不同的步长，通常开箱即用 |
| AdamW | Adam + 权重衰减，更好的正则化 |

Adam 结合了两个关键思想：
1. **动量**（Momentum）：利用历史梯度的平均方向
2. **自适应学习率**（RMSprop）：对于更新频繁的参数使用较小的学习率

```python
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
```

### 学习率的影响

| 学习率 | 效果 |
|--------|------|
| 太大（0.1） | Loss 剧烈波动，可能发散（NaN） |
| 适中（0.001） | Loss 稳定下降 ✅ |
| 太小（0.00001） | 下降极慢，需要很多 epoch |

> 💡 本项目默认使用 lr=0.001，这对于小模型是一个安全的起点。

## 四、如何观察训练过程

### 关键指标

#### 1. Loss（损失值）
- **正常**：应该整体呈下降趋势
- **异常**：如果 loss 不降或变成 NaN，说明有问题

```
期望的 loss 变化趋势：
Epoch 1:  Loss = 3.50  ← 开始时较高（接近 -log(1/vocab_size)）
Epoch 5:  Loss = 2.80  ← 开始下降
Epoch 10: Loss = 2.20  ← 继续下降
Epoch 20: Loss = 1.80  ← 下降变慢
Epoch 30: Loss = 1.50  ← 趋于稳定
```

#### 2. PPL（困惑度 / Perplexity）

$$\text{PPL} = e^{\text{Loss}}$$

困惑度可以直观理解为「模型的犹豫程度」：
- PPL = 65 → 模型在 65 个字符中随机猜（完全没学到东西）
- PPL = 10 → 模型在 10 个字符中犹豫
- PPL = 2 → 模型在 2 个字符中犹豫（非常确定）

#### 3. 生成文本质量

定期用模型生成文本，观察质量变化：

```
Epoch 1:   "aslkdjf 29sdf"          ← 完全随机
Epoch 10:  "the e and the s"        ← 开始出现常见词
Epoch 20:  "the king of my love"    ← 语法逐渐正确
Epoch 30:  "ROMEO: O, what light"   ← 出现莎士比亚风格
```

## 五、什么是过拟合？

### 定义

过拟合是指模型在训练数据上表现很好，但在新数据上表现差：

```
训练 Loss 和验证 Loss 的对比：

Loss
 │
 │    ╲  验证 Loss
 │     ╲╱───────────── ← 开始过拟合
 │      ╲
 │       ╲  训练 Loss 持续下降
 │        ╲────────────
 └──────────────────── Epoch
```

### 判断方法

| 指标 | 正常 | 过拟合 |
|------|------|--------|
| 训练 Loss | 下降 | 持续下降 |
| 验证 Loss | 同步下降 | **停止下降或上升** |
| 差距 | 训练≈验证 | **训练 << 验证** |

### 应对方法

| 方法 | 说明 |
|------|------|
| **Dropout** | 随机丢弃部分神经元输出（本项目使用 0.1） |
| **Early Stopping** | 验证 Loss 不再下降时停止训练 |
| **增加数据** | 更多训练数据 |
| **减小模型** | 降低 d_model、num_layers 等 |

## 六、Dropout 的作用

```python
self.dropout = nn.Dropout(0.1)
```

Dropout 在训练时随机将 10% 的神经元输出置为 0：

```
训练时:  [0.5, 0.0, 0.3, 0.0, 0.8]   ← 随机置零
推理时:  [0.5, 0.2, 0.3, 0.1, 0.8]   ← 保持完整
```

效果：
- 强制网络学习冗余的特征表示
- 类似于训练多个子网络的集成效果
- 有效减少过拟合

## 七、训练 Tips

### 梯度裁剪

```python
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

当梯度的范数超过 `max_norm` 时，按比例缩小梯度。防止极端梯度导致训练崩溃。

### Batch Size 的选择

| Batch Size | 效果 |
|-----------|------|
| 太小（4-8） | 训练噪声大，Loss 波动剧烈 |
| 适中（32-64） | 平衡了效率和稳定性 ✅ |
| 太大（256+） | 训练稳定但可能泛化能力差 |

### 训练检查清单

```
开始训练前：
  ☑ 数据加载正确（打印几个样本看看）
  ☑ 模型参数量合理（不要太大也不要太小）
  ☑ Loss 初始值合理（应接近 -log(1/vocab_size)）

训练过程中：
  ☑ Loss 在下降
  ☑ 没有 NaN 出现
  ☑ GPU/CPU 内存没有持续增长

训练完成后：
  ☑ 验证 Loss 和训练 Loss 差距不大
  ☑ 生成的文本有一定质量
  ☑ 模型已保存
```

## 八、小结

| 概念 | 关键点 |
|------|--------|
| 交叉熵损失 | 衡量预测分布与真实分布的差距 |
| Teacher Forcing | 训练时用真实标签作为解码器输入 |
| Adam 优化器 | 自适应学习率，推荐 lr=0.001 起步 |
| 过拟合 | 训练 Loss↓ 但验证 Loss↑ |
| Dropout | 随机丢弃神经元，防止过拟合 |
| 梯度裁剪 | 限制梯度范数，防止训练崩溃 |

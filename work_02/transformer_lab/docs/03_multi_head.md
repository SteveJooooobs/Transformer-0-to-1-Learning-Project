# 多头注意力机制

> 本文解释为什么需要多头注意力（Multi-Head Attention），它如何让模型同时从多个角度理解文本。

---

## 一、单头注意力的局限

在上一篇文档中，我们学习了缩放点积注意力。一组 Q、K、V 构成的注意力称为**单头注意力**（Single-Head Attention）。

单头注意力的问题：**它只能学习一种「关注模式」**。

举例来说，对于句子 "The cat sat on the mat"：
- 理解 "sat" 时，我们需要关注 "cat"（谁在坐？—— 语法关系）
- 同时，我们也需要关注 "mat"（坐在哪？—— 语义关系）

单头注意力只能在这两种关系之间做平衡，很难同时完美捕捉两者。

> 💡 **核心问题**：一个注意力头在一个位置只能产生一组权重分布，无法同时强烈关注多个不同的位置。

---

## 二、多头注意力的核心思想

**多头注意力的解决方案**：与其让一个头同时学习所有模式，不如让多个头各自专注于不同的模式。

```
单头：  Q → 一个注意力 → 输出
        （只能学一种模式）

多头：  Q → Head 1 → 关注语法关系
        Q → Head 2 → 关注位置邻近性
        Q → Head 3 → 关注语义相似性
        Q → Head 4 → 关注其他模式
        拼接所有头的输出 → 线性变换 → 最终输出
```

---

## 三、多头注意力的具体实现

### 步骤详解

#### 第 1 步：线性投影

将 $d_{model}$ 维的输入分别投影为 Q、K、V：

```python
Q = W_q(input)   # [B, L, d_model] → [B, L, d_model]
K = W_k(input)   # [B, L, d_model] → [B, L, d_model]
V = W_v(input)   # [B, L, d_model] → [B, L, d_model]
```

#### 第 2 步：拆分为多个头

将 $d_{model}$ 维度拆分为 $h$ 个大小为 $d_k = d_{model} / h$ 的子空间：

```python
# 拆分: [B, L, d_model] → [B, L, h, d_k] → [B, h, L, d_k]
Q = Q.view(B, L, h, d_k).transpose(1, 2)
K = K.view(B, L, h, d_k).transpose(1, 2)
V = V.view(B, L, h, d_k).transpose(1, 2)
```

> 💡 这里的技巧：不是创建 h 个独立的小矩阵，而是将一个大矩阵 reshape 成 h 份。这样用一次矩阵运算就同时完成了所有头的计算。

#### 第 3 步：每个头独立计算注意力

```python
# 每个头独立计算缩放点积注意力
# 因为 Q, K, V 的形状包含了 h 维度
# PyTorch 的矩阵运算会自动在 h 维度上并行处理
output, weights = scaled_dot_product_attention(Q, K, V, mask)
```

#### 第 4 步：拼接所有头

```python
# [B, h, L, d_k] → [B, L, h, d_k] → [B, L, d_model]
output = output.transpose(1, 2).contiguous().view(B, L, d_model)
```

#### 第 5 步：最终线性变换

```python
output = W_o(output)  # [B, L, d_model] → [B, L, d_model]
```

## 四、每个 Head 可能学到什么？

在训练完成后，不同的 head 通常会自发地学习到不同类型的关注模式：

| Head | 可能学到的模式 | 示例 |
|------|---------------|------|
| Head 1 | **位置关系** | 关注前一个或后一个词 |
| Head 2 | **语法关系** | 关注主语和谓语的对应关系 |
| Head 3 | **语义关系** | 关注语义上相关的词（同义词、反义词） |
| Head 4 | **长距离依赖** | 关注远处的关键词（如代词和其指代对象） |

> 💡 这些模式不是人为设定的，而是模型在训练过程中自己学会的。不同的 head 自发形成了「分工」。

---

## 五、Head 数量的选择

### 基本约束

$d_{model}$ 必须能被 $num\_heads$ 整除，因为：

$$d_k = \frac{d_{model}}{num\_heads}$$

| d_model | 合法的 num_heads |
|---------|-----------------|
| 64 | 1, 2, 4, 8, 16, 32, 64 |
| 128 | 1, 2, 4, 8, 16, 32, 64, 128 |
| 256 | 1, 2, 4, 8, 16, 32, 64, 128, 256 |

### 实际经验

| 设置 | 优缺点 |
|------|--------|
| **1 个头** | 退化为单头注意力，表达能力受限 |
| **2~4 个头** | 小模型的常见选择，计算量适中 |
| **8~16 个头** | 大模型的标准选择（BERT 用 12，GPT-3 用 96） |
| **太多头** | 每个头的 $d_k$ 太小，单个头的表达能力不足 |

> 💡 **本项目使用 4 个头**（d_model=128, d_k=32），这是一个适合教学的平衡选择。

## 六、总结

多头注意力的核心价值：

1. **多角度关注**：不同的头关注不同类型的关系
2. **更丰富的表示**：多个头的结果拼接后，特征表示更全面
3. **训练更稳定**：多个头的平均效果比单个头更稳定
4. **计算效率**：总计算量和单头注意力相当（因为每个头的维度更小）

```
多头注意力
    = 多个独立的注意力 head 并行工作
    = 从多个子空间同时提取信息
    = 更全面地理解输入序列
```
